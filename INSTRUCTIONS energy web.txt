1. PROJECT OVERVIEW
--------------------------------------------------------------------------------

A smart energy monitoring web application where households or building
managers enter appliance usage details, weather conditions and occupancy
data to predict energy consumption for the next hour or day (in Wh).

The system provides a full usage breakdown, cost estimation in Sri Lankan
Rupees using CEB tariff slab rates, anomaly alerts for unusually high usage,
and personalised energy-saving recommendations based on the predicted level.

Users can log their daily usage patterns and track their energy footprint
and estimated electricity bill over time — helping reduce costs and
carbon emissions.

--------------------------------------------------------------------------------
2. PROBLEM STATEMENT (Use in Proposal)
--------------------------------------------------------------------------------

Sri Lanka's electricity tariffs increased by 66% in 2023 (Ceylon Electricity
Board — CEB). Households receive their electricity bill only after the meter
is read at the end of the month — by which point it is too late to reduce
usage. There is currently no free, accessible online tool that allows
Sri Lankan households to predict their energy consumption in advance.

This system uses a Random Forest regression model trained on real household
sensor data to forecast electricity usage in Wh, and converts the prediction
into an estimated monthly bill using CEB's residential tariff slabs. Users
can identify which appliances waste the most energy and take corrective
action BEFORE the bill arrives — not after.

5. ML TRAINING STEPS (Step-by-Step)
--------------------------------------------------------------------------------

  Step 1 : Load Dataset
           import pandas as pd
           df = pd.read_csv('energydata_complete.csv')
           df['date'] = pd.to_datetime(df['date'])
           df.set_index('date', inplace=True)
           print(df.shape)   # (19735, 29)

  Step 2 : Exploratory Data Analysis (EDA)
           - Histogram: Appliances (Wh) distribution
           - Line plot: hourly usage over 4.5 months
           - Heatmap: correlation of all features
           - Box plot: usage by hour of day
           - Bar chart: average usage by day of week

  Step 3 : Feature Engineering
           df['Hour']       = df.index.hour
           df['DayOfWeek']  = df.index.dayofweek
           df['Month']      = df.index.month
           df['IsWeekend']  = (df['DayOfWeek'] >= 5).astype(int)

           # Lag feature (previous hour usage)
           df['prev_hour_usage'] = df['Appliances'].shift(1)
           df.dropna(inplace=True)

           # Time of day category
           def time_category(hour):
               if 6  <= hour < 12: return 'Morning'
               elif 12 <= hour < 17: return 'Afternoon'
               elif 17 <= hour < 21: return 'Evening'
               else: return 'Night'
           df['TimeOfDay'] = df['Hour'].apply(time_category)

  Step 4 : Drop Irrelevant Columns
           df.drop(['rv1', 'rv2'], axis=1, inplace=True)
           # rv1 and rv2 are random variables in the dataset — remove them

  Step 5 : Encode Categorical Features
           from sklearn.preprocessing import LabelEncoder
           le = LabelEncoder()
           df['TimeOfDay'] = le.fit_transform(df['TimeOfDay'])

  Step 6 : Scale Numerical Features
           from sklearn.preprocessing import StandardScaler
           scaler = StandardScaler()
           X = df.drop(['Appliances', 'lights'], axis=1)
           X_scaled = scaler.fit_transform(X)

  Step 7 : Train/Test Split
           from sklearn.model_selection import train_test_split
           y = df['Appliances']
           X_train, X_test, y_train, y_test = train_test_split(
               X_scaled, y, test_size=0.2, random_state=42)

  Step 8 : Train Random Forest Regressor
           from sklearn.ensemble import RandomForestRegressor
           reg = RandomForestRegressor(n_estimators=150,
                                       random_state=42,
                                       n_jobs=-1)
           reg.fit(X_train, y_train)

  Step 9 : Evaluate the Model
           from sklearn.metrics import mean_absolute_error
           from sklearn.metrics import mean_squared_error, r2_score
           import numpy as np

           y_pred = reg.predict(X_test)
           print('MAE: ',  mean_absolute_error(y_test, y_pred))
           print('RMSE: ', np.sqrt(mean_squared_error(y_test, y_pred)))
           print('R²: ',   r2_score(y_test, y_pred))

           # Plot predicted vs actual
           import matplotlib.pyplot as plt
           plt.scatter(y_test, y_pred, alpha=0.3)
           plt.xlabel('Actual'); plt.ylabel('Predicted')
           plt.title('Actual vs Predicted Energy Usage')
           plt.show()

  Step 10: Feature Importance
           importances = reg.feature_importances_
           # Prev_hour_usage and indoor temperature will dominate
           # Show top 10 features bar chart in your project report

  Step 11: Compare with Gradient Boosting (for extra marks)
           from sklearn.ensemble import GradientBoostingRegressor
           gbr = GradientBoostingRegressor(n_estimators=150, random_state=42)
           gbr.fit(X_train, y_train)
           # Show comparison table in report

  Step 12: Save Models
           import pickle
           pickle.dump(reg,    open('energy_rf_model.pkl', 'wb'))
           pickle.dump(scaler, open('energy_scaler.pkl',   'wb'))
           # Load in Flask:
           reg = pickle.load(open('energy_rf_model.pkl', 'rb'))

7. COMPARABLE WEBSITES & WEAK POINTS
--------------------------------------------------------------------------------

  WEBSITE 1: Ceylon Electricity Board (ceb.lk)
  -------------------------------------------------
  What it does  : Monthly electricity billing for Sri Lankan consumers
  Weak point    : No bill prediction tool at all. Users see their bill
                  only after meter reading at month end. No usage analytics,
                  no forecasting feature, no mobile-friendly interface.
  Your advantage: First Sri Lankan energy consumption predictor for
                  households — with bill estimation using CEB tariff slabs.

  WEBSITE 2: Google Nest / Smart Thermostat (nest.com)
  -------------------------------------------------
  What it does  : Smart home energy monitoring via hardware thermostat device
  Weak point    : Requires expensive hardware ($250+ device). Not sold or
                  supported in Sri Lanka. Software-only solution not available.
                  Data locked inside device ecosystem.
  Your advantage: Free web-based tool — no hardware required. Just enter
                  your usage data manually and get instant prediction.

  WEBSITE 3: EnergyStar.gov (US Government Tool)
  -------------------------------------------------
  What it does  : Static calculators for appliance energy rating (US-focused)
  Weak point    : US-only focus. No ML model. No personalised prediction
                  based on real usage patterns. Static lookup tables only.
  Your advantage: ML-based, real-time, fully adaptable to Sri Lanka's
                  local electricity tariff rates and tropical climate data.

  WEBSITE 4: Sense Energy Monitor (sense.com)
  -------------------------------------------------
  What it does  : AI-powered home energy monitoring via hardware device
  Weak point    : Hardware device required ($299 USD). No standalone web
                  prediction available. Not available or shipped to Sri Lanka.
  Your advantage: 100% software solution, free, accessible from any browser
                  without any hardware device installation.
