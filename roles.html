👤 Role 1 — Regular User (Household Member)
The primary end-user — any household member who wants to predict and manage their electricity usage
A Regular User is any person who registers on the system to predict their household energy consumption, estimate their monthly electricity bill, and get energy-saving tips. This is the most common role. They can only view and manage their own personal data and predictions — they cannot access other users' data or any admin features.
Self Registration Personal Data Only Most Common Role No Admin Access
Core Functions
📝 Register & Login to Personal Account Auth ▼
Users self-register using their name, email and password. The system creates a secure account linked to all their future predictions and usage history. Passwords are hashed using bcrypt before storing in MongoDB.
1
Go to Register Page — enter full name, email and password
2
System checks for duplicate email and validates format
3
Password is hashed with bcrypt and stored securely in MongoDB
4
User is automatically logged in and receives a JWT token (7-day expiry)
5
Redirected to their personal dashboard
⚡ Predict Energy Consumption Core ML ▼
The main feature. The user enters current household conditions (temperature, active appliances, occupants) and the Random Forest ML model returns a predicted energy usage in Wh for the current hour.
1
Open Consumption Predictor page
2
Enter: indoor temperature, number of occupants, appliances active, outdoor weather, time of day
3
Click Predict — React sends data to Node.js API → Flask ML microservice
4
Flask runs Random Forest Regressor and returns predicted Wh value
5
Result card shows: predicted Wh, usage category badge (Low/Normal/High/Very High), estimated hourly cost in Rs.
6
Prediction is saved to MongoDB under the user's account for history tracking
🧾 Estimate Monthly Electricity Bill Bill ▼
Users enter their estimated monthly total kWh usage and the system calculates their expected CEB electricity bill using Sri Lanka's residential tariff slabs — showing a full breakdown by slab.
1
Go to Bill Estimator page
2
Enter estimated total monthly usage in kWh
3
System applies CEB residential tariff slabs (0–30 units, 31–60, 61–90, etc.)
4
Shows per-slab cost breakdown and total bill in Rs.
5
Displays "How to reduce your bill" tips based on usage level
📊 View Personal Usage Analytics Dashboard Analytics ▼
Users can view charts and trends based on their own saved predictions — helping them understand when and how they use the most energy in their household.
1
Line chart: predicted usage trend over the past 7 / 30 days
2
Bar chart: average usage by day of week (which day uses most energy)
3
Bar chart: average usage by hour of day (morning vs evening peaks)
4
Summary card: estimated monthly bill based on logged predictions
📜 View & Manage Prediction History History ▼
All past predictions are saved in MongoDB and listed in a history table. Users can view, filter and delete their own past records.
1
Navigate to Prediction History page
2
Table shows: date/time, inputs used, predicted Wh, usage category, cost estimate
3
Filter by date range or usage category
4
Delete individual records or clear all history
💡 View Personalised Energy Saving Tips Tips ▼
After each prediction, the system shows tailored energy-saving tips based on the predicted usage category. If "Very High" is predicted, it shows tips targeting AC units, water heaters and refrigerators specifically.
1
Tips are automatically shown after each prediction based on usage category
2
User can also browse the full Tips Library page by appliance category
3
Tips are stored in MongoDB tips collection and managed by Admin
✏️ Edit Profile & Manage Account Profile ▼
Users can update their personal details, change their password, or permanently delete their account and all associated data from the system.
1
Edit name and email from Profile settings page
2
Change password after verifying current password
3
Delete account — permanently removes user + all predictions from MongoDB

⚙️ Role 2 — System Administrator
Full system control — manages users, content, ML model and system performance
The Administrator has complete control over the entire system. They manage all user accounts and roles, manage energy tips content, monitor system-wide analytics, handle ML model performance, and maintain overall system security. Typically only 1–2 Admin accounts exist, created directly in the database during initial system setup.
Full Access User Management Content Management ML Model Control System Analytics
Core Functions
👥 Manage All User Accounts User Mgmt ▼
Admin can view all registered users in the system, search and filter by various criteria, edit user details, change roles, suspend accounts or permanently delete users.
1
Access User Management page in Admin Panel
2
View table of all users: name, email, role, registration date, total predictions made
3
Search / filter users by name, email, role or registration date
4
Edit any user's name, email or assigned role
5
Suspend a user account — blocks login without deleting their data
6
Permanently delete a user and all their predictions from MongoDB
🔑 Assign & Manage User Roles Roles ▼
Admin controls which role each user is assigned. When an Energy Analyst or Building Manager requests elevated access, Admin reviews and approves or rejects the request.
1
User submits a role upgrade request with their reason
2
Admin sees a pending requests notification in the Admin Panel
3
Admin reviews the request and clicks Approve or Reject
4
If approved, user's role field in MongoDB is updated immediately
5
Admin can also manually change any user's role at any time
💡 Manage Energy Saving Tips Content Content ▼
Admin creates, edits and deletes energy-saving tip articles in the tips library. Tips are tagged by appliance type and usage level so users see relevant advice after each prediction.
1
Access Content Management page in Admin Panel
2
Add new tip: enter title, content body, usage level tag (Low/High etc.), appliance tag (AC/Fridge/Lights)
3
Edit existing tips to update outdated energy advice
4
Delete tips no longer relevant
5
All tips stored in MongoDB tips collection and fetched dynamically by React frontend
📊 View Full System-Wide Analytics Analytics ▼
Admin has access to a complete analytics dashboard showing platform-wide statistics — total users, total predictions, most common usage categories, peak usage hours, and new registration trends.
1
Summary cards: Total Users / Total Predictions / Active Today / Avg Predicted Wh
2
Line chart: new user registrations over time (daily / weekly / monthly)
3
Bar chart: total predictions submitted per day over the past month
4
Donut chart: usage category distribution across all predictions (Low/Normal/High/Very High)
5
Bar chart: peak prediction hours — what time of day users check their usage most
🤖 Monitor & Update ML Model ML Control ▼
Admin can view current ML model performance metrics and trigger a retraining workflow when new data is available or if prediction accuracy degrades over time.
1
Access ML Model Management page in Admin Panel
2
View: model version, training date, dataset size, R² score, MAE, RMSE
3
View recent prediction distribution chart to detect model drift
4
Click Retrain Model — triggers Flask API to retrain on latest dataset
5
New .pkl model file replaces old one after retraining is complete
🔒 View Audit Logs & Security Events Security ▼
Admin can view a log of all significant system events — logins, role changes, data exports and model updates — for security monitoring and accountability.
1
Access Audit Log page — lists all events with timestamp, user and action type
2
Filter logs by: action type, specific user, date range
3
Detect suspicious activity: multiple failed logins, mass data exports
4
Every role change, ML model update and account deletion is automatically logged

1
Go to Announcements page in Admin Panel
2
Create announcement: title, message body, expiry date

Saved to MongoDB announcements collection
4
All users see the announcement banner on their dashboard until expiry date
📤 Export System Data Reports Export ▼
Admin can export full system data reports — anonymised prediction records, user registration statistics — as CSV files for external reporting or analysis.
1
Go to Data Export section in Admin Panel

Choose export type: All Predictions / User Stats / Tips Usage

Select date range filter

⚡ Role 3 — Energy Analyst (Recommended Additional Role)
A verified professional who analyses energy data across multiple households or zones
An Energy Analyst is a professional (e.g. a utility company employee, environmental consultant, or government energy officer) approved by the Admin to view anonymised aggregate energy usage data across the platform. They can run bulk predictions, analyse trends across regions or building types, and generate official energy consumption reports. They cannot see individual user personal details.
Admin Approved Anonymised Data Bulk Predictions Report Generation
Core Functions
📈 View Aggregate Energy Analytics Dashboard Analytics ▼
Energy Analysts can access a system-wide analytics dashboard showing aggregate, anonymised energy usage patterns across all users — grouped by building type, region, time of day and season. No individual user data is visible.
1
Login and access Analyst Dashboard (separate from regular user dashboard)
2
View average predicted Wh by building type (House / Apartment / Office)
3
View peak energy hours across all users (line chart by hour of day)
4
View seasonal consumption trends (summer vs winter average usage)
5
All data shown as group statistics only — no personal data exposed
📤 Upload Bulk Prediction CSV Bulk ML ▼
Energy Analysts can upload a CSV file containing multiple households' or zones' energy input data, and the system runs the ML model on all rows at once — returning a batch of predictions.
1
Go to Bulk Prediction page (not available to Regular Users)
2
Upload CSV file with multiple rows of input data (temperature, appliances, occupants etc.)
3
System sends CSV to Flask ML API which runs prediction on all rows
4
Results table shows predicted Wh for each row
5
Download results as output CSV with predictions appended

Set date range and optional filters
4
Download as PDF or CSV

Use filter panel on Analyst Dashboard

1

🏢 Role 4 — Building Manager (Recommended Additional Role)
Manages energy monitoring for a specific multi-unit building or property
A Building Manager is responsible for a specific commercial building, apartment complex or office property. They can monitor and predict energy usage for their entire building, set usage alerts for individual floors or units, compare consumption across their property, and generate monthly energy reports. They can see data from all units within their building but NOT other buildings' data.
Admin Approved Building-Scoped Access Alert Management Unit Monitoring
Core Functions
🏗️ Register & Manage Building Profile Building ▼
The Building Manager registers their property in the system with details about building type, number of floors, units and average occupancy — creating a building profile that links all future energy predictions to that property.
1
Access Building Management page
2
Register building: building name, type (office/apartment/commercial), number of units, floors, location
3
Building profile saved to MongoDB buildings collection
4
All energy predictions linked to this building will be grouped under this profile
5
Admin must approve the building registration before full access is granted
📊 View Building-Wide Energy Dashboard Dashboard ▼
The Building Manager has a dedicated dashboard showing aggregated energy usage across all units in their building — with breakdowns by floor, time of day and appliance category.
1
Access Building Dashboard after login
2
Summary cards: total building Wh predicted today, estimated daily cost Rs., most active floor
3
Bar chart: energy usage per floor
4
Line chart: total building usage trend over the past week/month
5
Access is limited to their own building only — cannot see other buildings
🚨 Set & Receive Energy Usage Alerts Alerts ▼
Building Managers can define energy usage threshold alerts — e.g. if a floor exceeds 500 Wh in a single hour, an alert is triggered on their dashboard so they can investigate and take action.
1
Go to Alert Settings page
2
Set threshold: e.g. "Alert me if any floor exceeds 500 Wh per hour"
3
When a prediction exceeds the threshold, an alert appears on the dashboard
4
Alert shows: floor number, predicted Wh, time, severity (Medium / High / Critical)
5
Alerts are saved in MongoDB alerts collection for historical review
🔮 Run Building-Level Energy Prediction ML ▼
Building Managers can run a whole-building energy prediction by entering building-level conditions — average indoor temperature, total occupants, total active appliances — to get an estimated total Wh for the building.
1
Open Building Predictor page
2
Enter: average indoor temp, total occupants, total active appliances, outdoor weather
3
Flask ML model returns predicted total Wh for the building
4
Shows estimated cost for the building in Rs. using CEB commercial tariff rates
5
Prediction saved to MongoDB building predictions collection
📄 Generate Monthly Building Energy Report Reports ▼
Building Managers can generate a monthly energy consumption report for their building — showing usage trends, peak periods, estimated cost and energy-saving recommendations.
1
Go to Report Generator page
2
Select month and year
3
Report includes: total Wh, daily breakdown, peak usage day, estimated Rs. cost, saving tips
4
Download as PDF file
📅 View & Compare Historical Building Usage History ▼
Building Managers can compare their building's energy usage across different months or seasons to identify trends and improve energy efficiency planning.
1
Access Usage History page
2
Select two months to compare side by side
3
View month-on-month change in total Wh and estimated cost
4
Identify high-usage periods (holidays, summer months) for better planning
